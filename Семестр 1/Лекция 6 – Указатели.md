Память похожа на оооооочень длинный массив байт, где индексы этого массиива – адреса, а значения массива – значения в памяти.

**Адрес** – номер памяти с нуля, обозначающийся целым числом '&' – операция взятия адреса переменной.

Указатель (pointer) – переменная, хранящая адрес ячейки памяти.

`char *ptr;` – вот так объявляется тип данных "указатель".

```C
char a = 'A' // 65
char *ptr;
ptr = &a;
```

### Разыменовывание переменной 

```C
char a = 'A' // 65
char *ptr;
ptr = &a;
*ptr = 67; // переход на адрес ptr и изменение данных на 67
```

Разыменовывание (deference ) – переход по адресу, что хранится в переменной-указатели для считывания или записи по указанному адресу.

### Void pointers

```C
void *ptr; // ОШИБКА: Указатель на пустоту
```

Void-указатель нельзя разыменовать без явного преобразования в другой тип.
```C
int a = 5;
void *ptr = &a;
  
char b = *((char *)ptr);
```

### NULL
Для указателей есть свой 0 – NULL. NULL – адрес на нулевую ячейку памяти. Всем программам доступ к ней закрыт и при разыменовывании получим Segmentation fault.

## Динамические массивы
### malloc 
**malloc** – **M**emory **ALLOC**ation – выделяют динамическую память для хранения данных. Принимает один аргумент – количество байт для выделния, а возвращает адрес начала выделенной памяти.

### calloc 
**calloc** делает то же самое, что и **malloc**, но инициализирует данные нулями. Первый аргумент – количество элементов, второй – количество байт для каждого элемента.

### free
**free()** – освободить память по адресу

## Стек VS Куча (Stack VS Heap)
Stack – быстрая и упорядоченная область памяти, работающая по принципу LIFO (Last In, First Out)

Heap – большая и гибкая область памяти, где можно выделять блоки произвольного размера вручную. Управление памятью лежит на программисте (или, в некоторых ЯП, сборщике мусора)

### Модель памяти языка Си
**Модель памяти** – абстракция, с помощью которой описывается взаимодействие программы с памятью.

Любая программа на языке Си в памяти можно представить как следующие секции:

1. Text – код программы (текст), здесь все функции с кодом
2. Data – данные, тут хранятся все глобальные переменные явно проинициализированные чем угодно кроме нуля
3. BSS (Block Started by Symbol) – все глобальные переменные, что инициализированные 0 или ничем.
4. Heap – секция кучи, вся динамически выделяемая память через malloc, calloc, realloc
	1. Stack – секция стека, все локальные переменны, вызовы функций

## Виртуальная и физическая память 
Виртуальная как и физическая память разбиваются на блоки фиксированного размера – страницы (обычно 4 КБ). Когда программа пытается получить доступ к своей виртуальной памяти, ОС и процессор и чип MMU (Memory Management Unit) переводят виртуальный адрес в физический. Также и процессор требует перевода виртуального адреса в физический для работы с данными.
