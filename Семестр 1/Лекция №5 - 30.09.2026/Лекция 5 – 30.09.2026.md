# Массивы

**Массивы** используются для хранения нескольких значений в одной переменной, вместо объявления отдельных переменных каждого назначения.

```C
int scores[3] = {33,55,66};
```
**Индексация** элементов начинается с `0` в большинстве языков. (Поддерживается отрицательная индексация)
Исключения, где индексация начинается с `1`: MATLAB, lua, R, Julia 

```C
int scores[] = {3, 60, 2};
```

```C
int d[6] = {[3] = 9};
```

> [!warning]
> 
> В C можно выходить за рамки массивов, включая чтение и запись. Но тогда мы будем читать и писать в чужую память, не принадлежащую массиву.

> Вы, конечно, можете выйти за рамки массива, но вы тоже не барзейте, иначе будет

==**Segmentation Fault**== – попытка обратиться за рамки адресного пространства нашей программы.

Узнать размер массива можно:
```C
int m = {1,2,3}
int arr_size = sizeof(m) / sizeof(m[0]) // 12/4=3 
```

## Вставка / удаление элементов

В классическом (статическом) массиве **нельзя** менять размер массива.

"Удалить" элемент можно сдвигом хвоста влево:
```C
for (int i = pos; i<n-1; i++) arr[i] = arr[i+1]
```

> [!important]
> В функцию **можно** передать массив, но вернуть **нельзя**.
