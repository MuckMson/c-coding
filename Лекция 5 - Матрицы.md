# Матрица

Если переменная – коробка со значением, то массив – шкаф с коробками, а матрица – комната со шкафами.

Матрицы могут быть **многомерными**. 

```C
#define N 5
int matrix[N][N];
for (int i = 0; i<N; i++){ // Пробегаемся по всем строкам
	for (int j = 0; j<N;i++){ // Пробегаемся по соответствующему элементу столбца
		matrix[i][j] = ...; // Заполнение ячейки матрицы
	}
}
```

**Row-мажор** – порядок хранения матрицы в памяти по строкам.

#### Вывод по главной диагонали:
```C
#define N 5
int matrix[N][N];
for (int i = 0; i < N; i++){
	printf("%d", matrix[i][i])
}
```


#### Вывод по побочной диагонали:
```C
#define N 5
int matrix[N][N];
for (int i = 0; i < N; i++){
	printf("%d", matrix[i][N-1-i])
}
```

## Транспонирование матрицы 

```C
for (int i = 0; i<N; i++){
	for (int j = 0; j<N;j++){
		int tmp = matrix[i][j];
		matrix[i][j] = matrix[j][i];
		matrix[j][i] = tmp;	
}
```

## Свёртка матриц (свёрточные нейросети, размытие картинки)

```C
for (int i = 0; i< H; i++){
	for (int j = 0; j < W; j++){
		// пробегаемся поэлементно 
	}
}
```

# Строки

В **C** **нет отдельного типа*** данных string или типа того, все строки – **массивы символов.**
```C
char str[] = "Hello, Muck!";
printf("%s", str);
```

**Нул-терминатор ('\0')** показывает компьютеру, где заканчивается строка. Компилятор проставляет эти символы самостоятельно.

Для хранения массива строк мы можем использовать двумерный массив.

```C
char words[2][6] = {"Hi!","Apple"}; // Всегда выделяем на 1 символ больше для символа, так как в конце будет добавлен нул-терминатор.

// Здесь [2] – количество элементов слов
// [6] - длина самого длинного слова + 1 
```

## Безопасность scanf()

**scanf() не очень безопасен**, так как может произойти переполнение памяти, если количество введенных данных пользователем меньше, чем выделенное количество памяти.

Можно ограничить количество получаемых данных вот так:
```C
scanf("%7s", &x); // ограничит до 7 символов
```

## Функции для работы со строками – string.h

`strlen()` – получить длину строки не включая нул-терминатор
`strcpy()` – копирование одной строки в другую
`strncpy()` – strcpy(), но не выходя за размер n
`puts()` – вывод строки на экран
`fgets()` – ввод строки с клавиатуры
``strcmp()` – сравнение двух строк 
`strncat()` – добавить к строке строку + указание на количество свободного места в строке

## Функции для работы с символами – ctype.h
`isalpha(char c)` – символ это буква?
`isdigit(char c)` – символ это цифра?
`isspace(char c)` – символ это пробел?
`isupper(char c)` – символ в верхнем регистре?
`toupper(char c)` – перевести символ в верхний регистр
`tolower(char c)` – перевести символ в нижний регистр

snprintf(target, size, format....) – пишет в строку с ограничением по размеру, возвращает новую строку

## Сортировка 
**Сортировка** – алгоритмы для упорядочивания данных в массивах. С отсортированными списками обычно проще и быстрее работать.
