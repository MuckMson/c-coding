# Предпроцессор
1. Раскрывает директивы предпроцессора в начале кода (#include)
## Директива #include
Есть два способа написания этой директивы:
1. `#include <stdio.h>` – начинает поиск с стандартных путей к файлам
2. `#include "my_header.h"` – начинает поиск заголовчного файла с локального файла 

## #define – макроопределение (макрос)
`#define` – директива, предназначенная для макроопределений констант 

```C
#define N 128 
#undef N // N более не существует
```

```C
#define ADD(a,b) a+b
#define MIN(a,b) (a<b ? a :)
```

### Предопределенные константы 
`__LINE__` – номер строки
`__FILE__` – имя файла
`__FUNCTION__` – имя функция
`___DATE__` – дата компиляции программы
`__TIME__` – время компиляции программы 

### Условная компиляция 
```C
#if B == 5
// Code block to be executed
#else
// Code block to be executed
#endif
```
gcc file.c -DB=5

```C
#ifdef DEBUG
	// ...
#endif
```
gcc file.c -DDEBUG=1

```C
#ifndef DEBUG
	// ...
#else
	// ...
#endif
```
Её можно вставлять куда угодно, оборачивать в условия любые блоки программы, какие только хочется.
