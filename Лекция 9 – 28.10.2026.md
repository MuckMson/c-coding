# GIT 

GIT (система контроля версий) – распределенная система управления версиями. Проект был создан Линусом Торвальдсом для управления разработкой ядра Linux, первая версия выпущена 7 апреля 2005.

Простыми словами Git – программа, которая позволяет просматривать историю изменений файлов с кодом.

Что можно делать в Git?
1. Отслеживать изменения файлов 
2. Откатывать изменения (revert) к последней работающей версии
3. Тестировать изменения в коде, не меняя работающий оригинал. 
4. Синхронизовать изменения между разными людьми или устройствами, где последняя актуальная версия кода. его историей хранится на некотором сервере
