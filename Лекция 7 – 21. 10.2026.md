# Функции (часть 2)
**Рекурсия** – поведение функции, при котором она вызывает *сама себя*

## Аргументы функции main()

```C
int main(int argc, char *argv[]){
	for (int i = 0; i < argc; i++){
		printf("argv[%d] = %s\n", i, argv[i]);
	}
}
```

Аргументы в функцию передаются из терминала при запуск программы:
```zsh
./output.exec arg1 arg2 arg3 arg4 arg5
argv[0] = output.exec
argv[1] = arg1
argv[2] = arg2
argv[3] = arg3
argv[4] = arg4
argv[5] = arg5
```

## Callback 

**Callback** (обратный вызов) – **функция обратного вызова в программировании** – передача исполняемого кода в качестве одного из параметров другому коду.

## API  (Application Programming Interface)

**API** – программный интерфейс приложения, описывает протокол взаимодействия *между программами*. Представляет собой набор классов, функций структур или констант.

## ABI (Application Binary Interface) 
ABI – двоичный интерфейс приложения, описывает набор соглашений для доступа приложения к ОС и низкоуровневым сервисам.
