
**Функция** – именованный *блок кода*, который можно повторно использовать.

**Функции помогают**:
- Избегать *повторения* кода 
- *Структурировать* программу
- Проще искать и *исправлять* ошибки.
``` C
ReturnType FunctionName(arguments){
	// code block to be exectuted
		return (value);
}
```

Пример функции на сумму двух чисел:

```C
int sum(int a, int b){
	return a+b;
}
```

 **void** - функция, которая ничего не возвращает.

**Объявление (declaration)** – сообщаем компилятору, кратко ее имя и какие типы данных
```C
float set_identity(int age, char sex, int height, int weight)
```

**Определение (definition)** - сообщаем компилятору, что делает функция (тело)

> [!warning]
> Если компилятор найдет вызов функции до её явного объявления, он выдаст предупреждение **implicit declaration**, так как такие мувы могут привести к неожиданному поведению программы.
> Но можно это исправить, использовав **прототип функции**.

**Прототип функции** – копия головы функции для объявления её выше вызова её функции.

```C
void woof(int n); // Определение (delcaration) прототипа

int main() {
    woof(5); // Вызывается до определения
}

void woof(int n) { // Определение (declaration)

    for (int i = 0; i < n; i++) {
        printf("woof!\n");
    }
    return;
} // definition
```


**Предикаты** – выражения или утверждения, которые могут быть либо истинными, либо ложными.
Хороший тон: `IsBusy(); IsEmpty(); IsEven()` 

Сеттеры/геттеры для установки/получения значений: `setName(); setGenre(); getMessage(); getTimeOfDay();`


# Битовые операции

Запись чисел в разных системах счисления:

```C
char dec = 123; // десятичная 
char hex = 0x7B; // шестнадцатеричная
char oct = 0173; // восьмеричная
char bin = 0b1111011; // двоичная
```

### Операторы

| Операнд | Значение        | Действие      |
| ------- | --------------- | ------------- |
| &       | AND (и)         | умножение     |
| \|      | OR (или)        | сложение >= 1 |
| >>, <<  | SHIFT (сдвиг)   |               |
| ~       | NOT (отриц.)    |               |
| ^       | XOR (искл. или) |               |
|         |                 |               |

При **сдвиге** все биты съезжают на *заданное количество битов*, все, что не влазит **теряется навсегда**.
